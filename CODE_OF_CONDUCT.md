# Code of Conduct

This project is a research catalog. Discussion is about datasets, licenses,
methods, and corrections.

## Expected behavior

- Critique sources, counts, and access terms, not people.
- Bring a primary source when you challenge an entry.
- Say when a figure is unknown rather than filling the gap.
- Keep patient data, screenshots of identifiable studies, and access tokens
  out of issues, pull requests, and commits.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Posting credentials, download tokens, or attempts to bypass an access gate.
- Presenting controlled data as open, or a code repository as a data release.

## Reporting

Open a GitHub issue, or contact the repository maintainers privately if the
report should not be public. Maintainers may edit or remove material that
breaks this conduct standard or that exposes restricted data.
